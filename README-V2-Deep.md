## 🧰 KEY TOOLS & PROJECTS

### 🔐 C2 / BACKDOOR SYSTEMS
- [**C2-YakuzaDesign**](https://github.com/davoodya/C2-YakuzaDesign) – Modular Python C2 framework for post-exploitation & training.
- [**YakuzaBackdoor Undetectable**](https://github.com/davoodya/YakuzaBackdoor_Undetectable) – Stealth backdoor prototype with encoded payload and anti-virus evasion.

### 🧨 CRACKING & PENTEST TOOLS
- [**YakuzaCracker**](https://github.com/davoodya/YakuzaCracker) – High-performance brute-force/dictionary password and file cracking tool.
- [**pythonInBlack**](https://github.com/davoodya/pythonInBlack) – A collection of pentest scripts & utilities written in Python.

### 🔄 SYNC & REMOTE CONTROL
- [**Syncer**](https://github.com/davoodya/Syncer) – Seamlessly share clipboard and files between Linux & Windows using global hotkeys.
- [**OBS-Controller**](https://github.com/davoodya/obs-controller) – A powerful Tkinter GUI Panel to control OBS Studio from an external device.
- [**HTTP/HTTPS AttackerPentester**](https://github.com/davoodya) – Advanced HTTP protocol exploitation tool. (More info coming soon...)

### 🔐 PROFESSIONAL RANSOMWARE (POC) & MALWARE R&D 🧪

> ⚠️ **EDUCATIONAL DEMONSTRATION ONLY — NOT PUBLIC**

- **Ransomware Engine:** Multi-layer protection system with interval data deletion mechanism.
- **Advanced Evasion:** Self-hiding in EXE/ZIP files, anti-debugging, and virtual machine detection.
- **Military-Grade Encryption:** Triple encryption combining **AES-256**, **RSA-4096**, and **Custom XOR Algorithm** to prevent cracking by cyber defense teams.
- **C2 Integration:** Fully functional command & control server for monitoring and payload management.
- **Purpose:** Proof of concept for academic and defensive security research only.
